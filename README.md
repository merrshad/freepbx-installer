
# FreePBX Auto Installer Script

 A simple automated installer script for setting up **FreePBX** and **Asterisk** on Debian/Ubuntu-based systems.

---

## Features

- Installs all necessary dependencies
- Downloads and compiles Asterisk from source
- Installs FreePBX with default modules
- Configures services and sets up systemd startup
- Interactive confirmation before installation

---

## Usage

1. Clone the repository or download the script.

2. Make the script executable:

   chmod +x install_freepbx.sh

then run the script : 

   sudo ./install_freepbx.sh
